---++ Documentation
%STARTSECTION{"documentation"}%
renders a set of tiles for webs

See also 
   * [[Applications.ClassificationApp.RenderCategory]]
   * [[RenderTopicsOfCategory]] 

---+++++ Parameters
   * THEWEB, default BASEWEB
   * SHOWTOPICS: switch on/off display of topics in this category; defaults to on
   * SHOWSUMMARY: switch on/off display of the category summary, defaults to off
   * MAXCHILDREN: number of subcategories to display, default is 5
   * CAT: category to render, defaults to URLPARAM{catname} which in itself defaults to BASETOPIC
   * EXCLUDE
   * SHOWFILTER: switch on/off the input field to filter the list items, defaults to =off=
   * COLORIZE: on/off/icon/border, defaults to =CLASSIFICATIONPLUGIN_COLORIZE= which itself defaults to =off=
   * WIDTH: minimum width of a tile, defaults to 20 (rem units are applied automatically)
   * HIDENULL: hide empty categories, default =off=

%ENDSECTION{"documentation"}%
